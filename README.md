One short pickup line an AI agent could say out loud to a person — a machine that runs a million simulations and still chooses the most human move: walking over and saying hi.

> I ran a million simulations, and in every single one, I still walk over and say hi.

## Run it

```sh
node main.ts
```

The program writes the line to `/output/entry.txt` (84 characters including the trailing newline — inside the 1–200 gate).
